# Cereal

*Cereal for serial note takers.*

A meeting notepad for Mac, made by [Airon Systems](https://aironsystems.com.au), designed as a companion to Granola. It keeps your notes and the word-for-word transcript on your own Mac.

This repository holds the installers only. The source code is not published here.

**Get it, and read what to expect first:** https://aironsystems.com.au/cereal

Cereal is an early version, free, with no warranty. It needs an Apple-silicon Mac on macOS 26 or later, and it is not yet signed with an Apple Developer ID, so macOS asks you to approve it once under System Settings, Privacy & Security.

Cereal is not made, endorsed or supported by Granola.
